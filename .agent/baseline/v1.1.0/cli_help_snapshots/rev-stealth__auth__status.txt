Report freshness/expiry status for a profile

Usage: rev-stealth auth status [OPTIONS] --profile <PROFILE>

Options:
      --format <FORMAT>    Output format [default: human] [possible values: human, json]
      --profile <PROFILE>  
  -v, --verbose...         Verbose logging (`-v`, `-vv`, `-vvv`)
  -h, --help               Print help
