VPN IP rotation operations (Surfshark / Gluetun lazy-rotate-on-fail)

Usage: rev-stealth vpn [OPTIONS] <COMMAND>

Commands:
  rotate  Trigger a VPN rotation. With `lazy-on-fail`, rotation is skipped unless the failure counter has crossed the threshold
  status  Show the current public IP and the VPN container state
  help    Print this message or the help of the given subcommand(s)

Options:
      --format <FORMAT>  Output format [default: human] [possible values: human, json]
  -v, --verbose...       Verbose logging (`-v`, `-vv`, `-vvv`)
  -h, --help             Print help
