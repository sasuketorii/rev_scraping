CAPTCHA bypass operations (reCAPTCHA v2 / v3 / hCaptcha / Turnstile)

Usage: rev-stealth captcha [OPTIONS] <COMMAND>

Commands:
  solve   Solve a CAPTCHA challenge
  verify  Verify a previously-issued token (round-trips through the challenge provider's verify endpoint)
  help    Print this message or the help of the given subcommand(s)

Options:
      --format <FORMAT>  Output format [default: human] [possible values: human, json]
  -v, --verbose...       Verbose logging (`-v`, `-vv`, `-vvv`)
  -h, --help             Print help
