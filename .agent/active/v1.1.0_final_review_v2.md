## Additional Blockers

1. **Release identity mismatch.** `Cargo.toml` `[workspace.package] version`
   is still `1.0.0-dev`. `target/release/rev-stealth --version` prints
   `rev-stealth 1.0.0-dev`; `target/release/rev-auth --version` prints
   `rev-auth 1.0.0-dev`. A `v1.1.0` GA tag on binaries identifying as
   `1.0.0-dev` is not acceptable release evidence.
2. **No Git worktree metadata.** `git status --short` fails with
   `fatal: not a git repository`. This prevents proving committed
   `Cargo.lock`, clean tree, tag target SHA, or history-level gitleaks.
3. **`cargo package --workspace` still fails.** The checklist says this may be
   skippable because all crates are `publish = false`, but the command itself
   is not green and the release workflow still runs package dry-run on tag.
4. **Remote CI/artifact proof missing.** Local build produced only macOS arm64
   binaries. The 2 OS x 2 toolchain matrix and Linux release artifacts are not
   verified here.
