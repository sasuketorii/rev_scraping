# rev_harness 0.0.3 — Agent SDK billing separation compliance

リリース日: 2026-05 (PR-A 完了時点)
Plan 参照: `docs/plans/2026-06-agent-sdk-migration/plan-v3-final.md` PR-A

## 概要

Anthropic Agent SDK の billing separation 方針に追従するため、`scripts/claude-wrapper.sh` を
「明示 opt-in 経由でのみ Agent SDK サブプロセスを起動する shim」に書き換えた。
default 動作は task-tool への rewrite ガイダンスを返す passthrough であり、
意図せず Agent SDK credit を消費しないようにした。

## 主な変更

- `scripts/claude-wrapper.sh`
  - default で task-tool rewrite を案内するメッセージを返す
  - `--allow-agent-sdk` または `REV_HARNESS_ALLOW_AGENT_SDK=1` で従来の subprocess 起動
- `scripts/_shim-log.sh` 新規
  - shim 呼出を `~/.rev_harness/shim-hits.log` に JSONL で記録
  - 記録は ts / caller_hash / pid / ppid / rewrite_target / argv_hash の 6 フィールド
  - PII (prompt 本文・argv 生値) は SHA256 ハッシュ化のみで保存しない
- `docs/agent-sdk-policy.md` 改訂
  - opt-in 経路と billing 注意の明文化

## 互換性

- 既存呼出側 (cross_agent_wrapper_matrix_test 等) は明示 opt-in 経由に更新済み
- 外部 vendoring を行っていた利用者は `--allow-agent-sdk` を付与する必要あり

## アップグレード手順

1. `git pull`
2. `bash scripts/harness-doctor.sh` で構成を確認
3. Agent SDK を意図的に使う caller は `REV_HARNESS_ALLOW_AGENT_SDK=1` を export

## 既知の制限

- shim-hits.log のローテーションは 0.0.6 で導入予定 (cron スクリプトとして提供)
