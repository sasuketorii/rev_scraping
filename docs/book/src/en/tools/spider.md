# `spider`

> Scrape a URL with stealth (obscura) + optional CF evaluation + adaptive relocate. AUP allowlist required.

**Canonical schema**: [`docs/json-schemas/spider.output.json`](https://github.com/sasuketorii/rev_scraping/blob/main/docs/json-schemas/spider.output.json)
**Source**: [`crates/stealth-mcp/src/tools.rs`](https://github.com/sasuketorii/rev_scraping/blob/main/crates/stealth-mcp/src/tools.rs)

## Input arguments

| Field | Type | Required | Description |
|---|---|---|---|
| `url` | string | yes | Target URL. Must pass AUP allowlist + SSRF guard. |
| `session_id` | string (UUIDv4) | no | Correlate with a prior session; autogenerated when omitted. |
| `mobile_preset` | enum | no | One of `iphone15pro`/`iphone15promax`/`ipadprom4`/`pixel9pro`/`pixel8a`/`galaxys24ultra`. |
| `cf_evaluate` | boolean | no | Run the CF Turnstile evaluator alongside (default `false`). |
| `vpn` | boolean | no | Require an authenticated VPN egress before scrape. |
| `stable_id` | string | no | Stable element ID from a prior run; enables adaptive relocate. |
| `threshold` | number | no | Adaptive-relocate similarity threshold in [0,1] (default `0.85`). |
| `strict` | boolean | no | Fail closed on any non-canonical signal (default `false`). |

`inputSchema` has `additionalProperties: false` — unknown keys are rejected.

## Happy path

**Request**:

```sh
echo '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"spider","arguments":{"url":"https://example.com"}}}' \
  | rev-stealth mcp
```

**Response** (success envelope, abridged — see `outputSchema` link above
for the full field list):

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "isError": false,
    "content": [
      {
        "type": "text",
        "text": "{\"result\":{},\"operation\":\"spider\",\"ok\":true}"
      }
    ]
  }
}
```

The `text` field is a stringified JSON object that conforms to
`docs/json-schemas/spider.output.json`.

## Failure example — `Aup` (wire `kind: "aup"`)

If the URL is not on the AUP allowlist, the response is an `ErrorEnvelope`. The MCP layer
serialises `kind` as the snake_case `wire_name` (not the PascalCase Rust
variant), and `retryable: false` reflects whether retrying
without changing inputs is plausibly safe (see
`crates/stealth-agent-contracts/src/error.rs`, `all_error_kind_docs()`).

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "isError": true,
    "content": [{
      "type": "text",
      "text": "{\"kind\":\"aup\",\"message\":\"...\",\"retryable\":false,\"hint\":\"...\",\"doc_url\":\"https://sasuketorii.github.io/rev_scraping/en/errors/Aup.html\"}"
    }]
  }
}
```

Follow the [`Aup` troubleshooting page](../errors/Aup.md)
for the fix recipe.
