# Quickstart tutorial

Seven steps from `brew install` to an AI agent driving `rev-stealth` on a
VPS. Each step is independently runnable. Steps 4 (VPN) and 6 (Hermes) have
stub commands if you do not have those integrations on hand — the steps
still document the wire format and the exit codes.

1. [Local install](./01-local.md)
2. [Your first recipe](./02-recipe.md)
3. [Browser profile & cookies](./03-profile.md)
4. [VPN rotation](./04-vpn.md) (stub OK)
5. [Claude Code integration](./05-claude-code.md)
6. [Hermes orchestrator](./06-hermes.md) (stub OK)
7. [VPS deployment](./07-vps.md)

The whole tour is < 30 minutes assuming a working network and a fresh
`brew install`. Each chapter ends with a one-line **smoke test** you can
paste into your shell to confirm the step worked.
