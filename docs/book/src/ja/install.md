# インストール

[English version](../en/install.md) を参照してください。日本語要約のみ:

- macOS: `brew tap sasuketorii/rev-stealth && brew install rev-stealth`
- Debian/Ubuntu: GH Release から `.deb` を `dpkg -i`
- crates.io: `cargo install --locked rev-stealth`
- Docker: `docker pull ghcr.io/sasuketorii/rev-stealth:v1.3.0`

詳しくは英語版を参照。
