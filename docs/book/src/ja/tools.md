# MCP ツール一覧 (日本語)

16 個の MCP ツールの一覧 (詳細は英語版のクックブックを参照):

| Tool | 用途 |
|---|---|
| `spider` | 1 URL を取得しサニタイズ済み構造化出力を返す |
| `relocate` | ブラウザを別 IP / プロファイルへ移動 |
| `cf_evaluate` | Cloudflare チャレンジ評価 |
| `doctor` | 環境診断 |
| `recipe_list` | レシピ一覧 |
| `recipe_show` | レシピ詳細 |
| `recipe_remove` | レシピ削除 |
| `recipe_propose_endpoint` | レシピ提案 |
| `recipe_export` | レシピ書き出し |
| `recipe_import` | レシピ取り込み |
| `auth_login_start` | 認証開始 (デバイスフロー風) |
| `auth_login_complete` | 認証完了 |
| `auth_list` | 認証済みサイト一覧 |
| `auth_status` | 認証セッション状態 |
| `session_show` | アクティブセッション表示 |
| `vpn_rotate` | VPN ローテーション |

各ツールの JSON-RPC 例は英語版 [tools/](../en/tools/README.md) 参照。
